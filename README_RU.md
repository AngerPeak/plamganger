# PALM GANGER + PALMGANGER 9000 — мод для Minecraft 1.20.1 (Forge)

## Что в моде
- **PALM GANGER** — нейтральный пьяный моб (50 HP, урон 4). Медленный, после удара становится быстрее.
- **PALMGANGER 9000** — босс на танке (200 HP). Если не злить — с ним можно торговаться (ПКМ):
  24 изумруда → музыкальная пластинка. Если ударить — стреляет из пушки взрывными снарядами
  (взрывы не вредят самому танку).
- **Палмганговая руда** — генерируется в пещерах (только в НОВЫХ чанках!). Ломается железной киркой и лучше.
- **Блок Палмгангера** — 4 руды (2×2).
- **Палмганговый кристалл** — 4 блока Палмгангера по углам + 4 стекла + алмаз в центре:
  `Б С Б / С А С / Б С Б`
- **Палмовое ебалово** (призыватель) — кристалл в центре + 8 блоков Палмгангера вокруг.
  Поставил → на экране отсчёт 5…1 → взрыв (без разрушений) → появляется PALMGANGER 9000 и играет музыка.
  Нужно свободное место примерно 5×5×4 блока.
- Всё лежит в творческой вкладке **PALM GANGER** (там же оба яйца призыва).

## Установка мода (игроку)
1. Установи **Minecraft Forge 1.20.1** (47.x) — https://files.minecraftforge.net
2. Положи `palmganger-1.20.1-1.0.0.jar` в `%appdata%\.minecraft\mods`.
3. Запусти игру профилем Forge.

## Как получить .jar через GitHub
1. https://github.com/new → имя `palmganger` → Create repository.
2. **uploading an existing file** → перетащи всё СОДЕРЖИМОЕ папки `palmganger-mod` → Commit changes.
   (если репозиторий уже есть — просто загрузи поверх, файлы заменятся)
3. Если нет файла `.github/workflows/build.yml` — Actions → *set up a workflow yourself* → вставь текст из `build.yml` → Commit.
4. Actions → дождись зелёной галочки (2–10 мин) → открой запуск → **Summary** → внизу **Artifacts** → `palmganger-mod-jar`.
5. Распакуй zip → внутри `.jar` → положи в `mods`.

Либо на своём ПК: `BUILD_WINDOWS.bat` (нужен интернет) → мод появится в папке `OUTPUT`.

## Звуки (assets/palmganger/sounds.json)
- PALM GANGER: SOUND_1/2 — реплики, SOUND_3 — урон, SOUND_4 — злость, DEATH_SOUND — смерть.
- PALMGANGER 9000: две короткие фразы — реплики в покое, третья — злость, четвёртая — при появлении;
  урон и смерть — те же, что у PALM GANGER.
- Музыка (10 сек, файл FL Studio) — при появлении босса (тихо) и на пластинке.
Соответствие меняется в `sounds.json`.
