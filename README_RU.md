# PALM GANGER — мод для Minecraft 1.20.1 (Forge)

Нейтральный пьяный моб. HP 50, урон 4. Спокойный и медленный, пока его не ударишь — после удара
становится быстрее (+70% скорости) и атакует обидчика. Вокруг него розово-зелёные «зельевые» частицы,
а игроки рядом (≈5 блоков) получают эффект тошноты — экран качается, как будто пьяный.
Яйцо призыва (зелёно-красно-чёрное): креатив → вкладка «Яйца призыва». Моб ещё и сам спавнится в обычном мире.

## Установка (игроку)
1. Установи **Minecraft Forge 1.20.1** (47.x) — https://files.minecraftforge.net
2. Положи `palmganger-1.20.1-1.0.0.jar` в папку `mods` (Win+R → `%appdata%\.minecraft\mods`).
3. Запусти игру профилем Forge. Всё.

## Как получить готовый .jar (если его ещё нет)
**Вариант А — одним кликом на своём ПК:** распакуй архив → запусти `BUILD_WINDOWS.bat`
(Linux/Mac: `./build_linux_mac.sh`). Нужен только интернет; Java 17 скачается сама.
Готовый мод появится в папке `OUTPUT`.

**Вариант Б — без установки чего-либо:** залей папку в новый репозиторий на GitHub →
вкладка Actions → «Build mod» → скачай артефакт `palmganger-mod-jar`.

## Звуки (assets/palmganger/sounds.json)
SOUND_1 и SOUND_2 — случайная реплика в покое, SOUND_3 — получение урона,
SOUND_4 — когда разозлился, DEATH_SOUND — смерть. Менять соответствие можно в `sounds.json`.
